# CyberHunter

CyberHunter — це проста браузерна/десктопна клік-гра у стилі arcade, створена на Python за допомогою Tkinter. Гравець має влучати по рухомій цілі, заробляти очки, уникати промахів і проходити рівні зі збільшенням складності.

## Опис гри

Гра запускається у вікні з однією ціллю, яка випадково переміщується по області. Кожен правильний клік збільшує рахунок, а кожен промах по фону забирає одне життя. Коли рахунок досягає цілі, гравець виграє раунд і гра перезапускається.

## Основні механіки

- Випадкове переміщення цілі по полі
- Підрахунок очок і рівнів
- 5 життів на старті
- Збільшення складності з кожними 5 очками
- Зміна швидкості появи цілі
- Вікна перемоги та програшу через `messagebox`

## Функції

- Простий інтерфейс на Tkinter
- Адаптивний рівень складності
- Красива зміна фону під час прогресу або помилки
- Автоматичний перезапуск гри після завершення раунду

## Вимоги

- Python 3.8+
- Вбудований модуль `tkinter` (зазвичай йде разом із Python)

## Як запустити

1. Перейдіть в каталог проєкту.
2. Виконайте команду:

```bash
python game_clicker.py
```

3. Гра відкриється у вікні Tkinter.

## Управління

- Клік лівою кнопкою миші по цілі: +1 очко
- Клік по фону вікна: -1 життя
- Мета: набрати 100 очок

## Правила

- Якщо життя закінчилися, гра завершується.
- Кожні 5 очок збільшують рівень і прискорюють переміщення цілі.
- Гра виграна, коли рахунок досягає значення `goal`.
